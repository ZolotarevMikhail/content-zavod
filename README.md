# Контент-завод

**ИИ-конвейер контента под ключ:** сам находит темы в интернете, предлагает
идею, пишет пост — и публикует его в соцсети только после вашего одобрения.
Вы управляете заводом кнопками в Telegram, не открывая ни кода, ни таблиц.

Проект-шаблон: настраивается под любую тему и любые площадки за один вечер.
Подходит экспертам, предпринимателям и агентствам, которым нужен регулярный
контент без найма контент-менеджера.

## Что умеет

- **Поиск тем по вашему профилю** — завод сканирует открытые источники
  интернета и отбирает темы по вашей рубрике интересов (задаётся в анкете
  запуска: что важно — споры, эмоции, польза, свежесть — веса вы ставите сами).
- **Идея — на одобрение** — карточка темы в Telegram-боте: суть, почему
  тема спорная, ссылки на источники. Кнопки «одобрить / отклонить».
- **Пост — на одобрение** — после идеи завод пишет готовый пост под вашу
  площадку и ваш тон. Кнопки «опубликовать / переписать / отклонить».
- **Публикация одной кнопкой** — одобренный пост уходит в выбранные соцсети
  с отчётом в чате.
- **Ничего не теряется** — отклонённые идеи и черновики уходят в архив,
  история решений сохраняется.
- **Человек всегда решает** — автоматика никогда не публикует сама.

## Для кого

| Кто | Что получает |
|---|---|
| Эксперт / предприниматель | регулярный контент без найма копирайтера и без риска «нейросеть выложит чушь» |
| Селлер WB/Ozon | контент про товары и рынок по своему расписанию |
| Агентство / фрилансер | продукт для клиентов: настроил под заказчика — передал, клиент ведёт сам |

## Как выглядит снаружи

```
📱 Бот: «Идея поста: ...»            → вы: ✅
📱 Бот: готовый текст поста           → вы: ✅
🚀 Пост в канале, отчёт в чате
```

Всё управление — пятью кнопками в Telegram.

## Запуск

1. Заполните анкету запуска (`опросник-запуска.md`) — 32 вопроса о теме,
   аудитории, тоне, площадках и расписании.
2. Скопируйте `.env.example` в `.env` и вставьте свои токены (подсказки в файле).
3. Запустите:

```bash
python3 scripts/sbor.py   # поиск тем
python3 scripts/bot.py    # бот одобрения и публикации
```

Требуется Python 3.10+, без сторонних библиотек.

## Что внутри

- `scripts/` — конвейер: поиск тем, бот одобрения, публикация
- `config.json` — тема, источники, площадки, периодичность, правила
- `config/rubrica.md` — рубрика отбора тем (критерии и веса)
- `опросник-запуска.md` — анкета настройки + механизм передачи заказчику
- `ideas.md` — копилка идей

## Безопасность по устройству

- Токены — только в `.env`, в репозиторий не попадают.
- Публикация — только после ручного одобрения кнопкой.
- Все сетевые запросы — с ограниченным автоповтором, сбои видны в чате,
  «молчаливых» падений нет.
